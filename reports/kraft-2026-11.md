# Kraft · повторна ініціалізація оновлює skills

**Результат:** наш [PR #1227](https://github.com/itsOmidKarami/kraft/pull/1227) злитий 02.11.2026; merger — `itsOmidKarami`. Виправлення закриває [issue #1123](https://github.com/itsOmidKarami/kraft/issues/1123).

[English summary](#english-summary) · [Журнал результатів](../RESULTS.md)

## Проблема та зміна

Повторний user-scope запуск `kraft admin init` зупинявся, коли Claude CLI повідомляв, що MCP server уже зареєстрований. Через це застарілі skills не оновлювалися.

Команда тепер повідомляє про наявну реєстрацію, залишає її на місці й оновлює skills. Відсутній Claude CLI або інша помилка реєстрації й надалі зупиняє запис skills і показує команду для ручної реєстрації. Оновлено також довідку й приклади CLI output.

## Перевірка та прийняття

За [PR-звітом](https://github.com/itsOmidKarami/kraft/pull/1227), focused init suite — **16 passed** на Python 3.12.8; `just ci-checks` пройшов lint, format, docs, test-shape та intent-pin перевірки. Mutation checks окремо ламали відновлення після existing registration, повідомлення статусу й відмову при справжній помилці, зокрема порожньому stderr.

Тести підставляли відповідь Claude subprocess. Живі агентські виклики й зміни користувацької конфігурації не виконувалися. [Merge commit](https://github.com/itsOmidKarami/kraft/commit/ae8813d02015bfeddeea92d26bfc7ca1f85ef53d) фіксує прийняття виправлення.

## English summary

Our [PR #1227](https://github.com/itsOmidKarami/kraft/pull/1227), merged on 2 November 2026 through `itsOmidKarami`, fixes repeated user-scope `kraft admin init`: refresh stale skills when Claude reports an existing MCP registration, while retaining that registration. Missing CLI and other registration failures still stop before skill writes and show the manual command.

The published focused init suite passed 16 tests on Python 3.12.8, and `just ci-checks` passed. Mutation checks verified the successful refresh path, status output and genuine-error rejection. Tests used a subprocess double; no live agent call or user-configuration change was performed.
