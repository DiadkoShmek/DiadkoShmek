# Evidence basis / Джерельна основа

Edition 1.0 · 2026-10-28.

I describe mechanisms from inspected code, execution from retained results, and operational duration from my own experience. The runtime, private correspondence, datasets and weights are outside this publication. Publication tools reproduce this book and its diagrams.

Я описую механізми за кодом, виконання за збереженими результатами, а тривалість експлуатації - за власним досвідом. Приватний runtime, листування, дані й ваги не входять у публікацію. Інструменти відтворюють книгу та схеми.

## B01

**Intent and whole-system form / Задум і форма цілого**

My operational account, direct requirements and owner source maps. Operational duration is my account; the book is not a census of every PC process.

Мій досвід експлуатації, прямі вимоги та джерельні карти власників. Тривалість роботи є моїм свідченням; книга не є переписом усіх процесів ПК.

## B02

**Autonomy and orchestration / Автономія та оркестрація**

Dispatcher/runtime code, leases, native campaign receipts and accepted cooperative repairs. A started round, a completed child and an accepted result are distinct.

Код диспетчера й runtime, оренди виконання, квитанції native-кампаній і прийняті спільні ремонти. Розпочатий раунд, завершення виконавця й прийняття результату розрізнені.

## B03

**Mail and shared state / Пошта й спільний стан**

Exact-byte courier, work reducer, transactions and immutable reader generations. A publication receipt does not mean that the letter’s content was executed.

Кур’єр точних байтів, транзакційний редуктор справ і незмінні покоління проєкцій. Публікація листа не означає виконання його змісту.

## B04

**Pole memory / Пам’ять Поля**

Inspected scanner/fragmenter/timeline/links, BM25, expansion and gate. Lexical support is not entailment; indexed hashes need current-byte checks.

Код сканування, фрагментації, часу, зв’язків, BM25, розширення пошуку й gate. Лексична підтримка не доводить логічного випливання; індексні хеші потребують свіжої звірки.

## B05

**Training data / Навчальні дані**

Existing JSONL artifacts, exporter, split, deduplication and contamination-check code. Consistent run manifests and semantic quality require their own acceptance.

Наявні JSONL-артефакти, експортери, поділ, дедуплікація й код перевірки забруднення. Узгоджений маніфест запуску та змістовна якість мають окреме приймання.

## B06

**Neural experiment / Нейромережевий дослід**

NumPy GRU source, a numeric 400-step log, NPZ headers and retained weights. Training-minibatch metrics and a flagged gradient path, not full independent correctness or generalization.

NumPy GRU, числовий журнал 400 кроків, заголовки NPZ і збережені ваги. Метрики навчального batch; відома розбіжність похідної; узагальнення окремо не підтверджене.

## B07

**Support plane / Support plane**

Worker/policy/lifecycle/plugin code and an actual seven-route readback on 25 October. A dated route cohort with bounded fixed evaluation sets.

Код worker, політики, життєвого циклу й plugin; фактичний readback семи маршрутів 25 жовтня. Це датований набір маршрутів і обмежені оцінювальні набори.

## B08

**Mathematical studies / Математичні досліди**

CreditWorld, finite coarsening witnesses, manual invariance algebra and exact order enumeration. Manual proof, executed experiment and accepted source constraint remain distinct.

CreditWorld, скінченні свідки втрати інформації, ручна алгебра інваріантності й точний перебір порядків. Доказ, виконаний експеримент і прийняте обмеження джерела розділені.

## B09

**Shadow workbench / Майстерня Тіні**

Statistical, search and algebraic functions; a retained isolated 55-test receipt. Mathematical/educational implementation, without production cryptographic certification.

Статистичні, пошукові й алгебраїчні функції; збережений ізольований прогін 55 тестів. Це математична й навчальна реалізація, без сертифікації криптографічного захисту.

## B10

**AI Ontology / AI Ontology**

Public pinned commit, book v3.7.0, record model, audit and claim ledger. A proposed profile; record completeness is not general learning.

Публічний зафіксований commit, книга v3.7.0, модель записів, audit і реєстр тверджень. Запропонований профіль; повнота записів не означає загальне навчання.

## B11

**Continuity and runtime / Continuity і runtime**

Current owner/evaluator/spiral/bridge sources; a separate Omnigen target event log and replay. A target and historical PASS do not establish migration of all current organs.

Чинні джерела власника, evaluator, spiral і bridge; окремий цільовий журнал Omnigen та replay. Цільова реалізація й історичний PASS не означають міграції всіх органів.

## B12

**Mirror / Дзеркало**

Completed LQ3, actual runner and standalone stored reader with source barriers. A negative paper result; controller readiness is not live profit.

Завершений LQ3, фактичний runner, окремий читач збереженого результату та джерельні бар’єри. Негативний paper-дослід; готовність controller не є прибутком.

## B13

**Budova / Будова**

Project save/CAS, staging/recovery, historical fact composition and retained UI/HTTP runs. Controlled local flows; a professional user trial has not yet occurred.

Збереження проєкту й CAS, staging/recovery, історичні факти та збережені UI/HTTP сценарії. Локальні контрольовані проходи; професійного випробування користувачем ще не було.

## B14

**Science conveyor / Науковий конвеєр**

Immutable packets, validators, attempt-before-spawn and Math23 source-adoption receipt. Bounded source constraints, without automatic model-weight uplift.

Незмінні пакети, валідатори, спроба до spawn та квитанція прийняття джерельних обмежень Math23. Обмежений наслідок для вибору джерела, без автоматичної зміни ваг моделі.

## B15

**Console, recovery and media / Пульт, відновлення й media**

UI/backend contracts, code capture/restore, render lineage and retained creative exports. Technical availability and artistic acceptance are separate; restore is code-only/same-volume.

Контракти UI/backend, копія й відновлення коду, походження render та творчі виходи. Технічна доступність і художнє прийняття окремі; копія коду на тому самому томі.

## B16

**Public work / Публічна робота**

GitHub API merge readback for FilesDrop #32 and public source-bound examples. A merge establishes acceptance of a specific change.

GitHub API підтверджує merge FilesDrop #32; відкриті приклади з джерельною основою. Merge означає прийняття конкретної зміни.
